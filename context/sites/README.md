# context/sites

Offline captures of public websites so sessions without network access to them can still work on them.

Intended layout per site (`context/sites/<site>/`):

- `<slug>.html` — raw HTML of each page
- `<slug>_desktop.png` / `<slug>_mobile.png` — full-page screenshots at 1280 and 390 px wide
- `<slug>.md` — faithful Markdown transcription of all visible text, in order
- `NOTES.md` — tech stack signals, fonts, colours, forms and their submit targets, load notes, and (for katieglows) what /method sells
