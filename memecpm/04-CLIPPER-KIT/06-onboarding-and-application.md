# Application form, approval checklist, welcome flow

## Application form (Tally / Typeform / Google Form)

Title: **Apply to post for memecpm campaigns (2 minutes)**

1. Name or handle you go by
2. Discord username
3. Email (for payout notices)
4. Page links (TikTok / Instagram / YouTube), one per line
5. Followers on each page (approx.)
6. **Upload a screenshot of your audience analytics** (TikTok: Analytics → Followers → Top territories;
   Instagram: Insights → Followers → Top locations; YouTube: Analytics → Audience → Geography)
7. Niches you post in (multi-select: skincare/beauty, wellness/fitness, pets, food, gaming, entertainment,
   other)
8. Campaigns you've clipped for before (optional)
9. Payout method: [PAYOUT METHOD] handle/email
10. "I've read the rules and I'll label paid posts #ad" (checkbox, required)

Auto-reply: "Thanks — applications are reviewed within 48 hours. You'll get a DM on Discord either way."

## Approval checklist (Evan, 3 minutes per application)

- [ ] Analytics screenshot shows 40%+ US/UK/CA/AU
- [ ] Page is real: consistent posting, comments look human, likes visible, no obvious bought followers
      (followers vs. average views ratio isn't absurd)
- [ ] Niche fits at least one live or upcoming campaign
- [ ] No red flags: stolen content, other campaigns' watermarks, NSFW, drama pages
- [ ] Discord handle exists and joined the server

Approve → give the `Clipper` role, send DM #3 from `02-dm-templates.md`.
Decline → send DM #4. Keep a note; people reapply with better pages.

## Welcome flow (first 7 days)

**Day 0 (approval):** DM #3 + role. Bot posts "Welcome @name" in #general.
**Day 1:** they post 3 clips from the starter campaign and submit links.
**Day 3:** 72-hour view check; DM one sentence of feedback ("your question-hook posts are doing 2× the
demo cuts — lean in").
**Day 7:** first weekly "what's working" post lands; they're in the loop.
**Day 14/16:** first payout message (DM #6), even if small. Nothing retains clippers like a fast, exact
first payment.

## The three things that make clippers stay

1. **Pay on the date you said, with the maths shown.** Every time.
2. **Tell them what's working** weekly. They're guessing otherwise.
3. **Keep campaigns flowing.** A server with no live campaign empties in a fortnight. Even a small pool
   ($200–300) between big campaigns keeps people posting.
