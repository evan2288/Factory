# memecpm clipper kit

Everything needed to recruit, brief, run and pay a clipper community for memecpm campaigns. Modelled on
the briefs Evan already receives from Clipping Culture, ClipFarm and ElevenLabs (rules, tiers, payouts,
rejection reasons), so clippers who've worked those campaigns recognise the format instantly.

| File | What it is |
|---|---|
| `01-discord-announcements.md` | Recruiting posts for clipping servers (3 lengths) + the pinned "how it works" |
| `02-dm-templates.md` | DMs for cold outreach, follow-up, acceptance, rejection, payout notice |
| `03-how-it-works-one-pager.md` | The one page a clipper reads before applying |
| `04-campaign-brief-template.md` | The brief sent per brand campaign; fill the brackets |
| `05-rules-and-payouts.md` | Standing rules, verification, payout schedule, ban reasons |
| `06-onboarding-and-application.md` | Application form fields, approval checklist, welcome message |
| `07-discord-server-layout.md` | Channels, roles, bots, and the submission flow |
| `08-tracking-sheet.md` | Columns for the campaign tracker sheet (clipper submissions, views, payouts) |

Fill these placeholders once and they're used everywhere:
- `[SERVER INVITE]` — the memecpm Discord invite
- `[PAYOUT METHOD]` — PayPal / Whop / Wise
- `[RATE]` — default rate per 1,000 verified views (suggested $1.00–$1.50)
- `[APPLY LINK]` — the application form (Tally/Typeform/Google Form)
